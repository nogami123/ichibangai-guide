このフォルダには、イベントのチラシ画像などを入れます。
=======================================================

■ いま入れてほしい画像

  ファイル名： event-hirunomi.jpg

  「昼飲み＆限定ランチフェア」のチラシ画像を、
  この名前でこのフォルダに保存してください。

  （保存のしかた）
    1. チラシ画像を右クリック →「名前を付けて画像を保存」
    2. 保存先を  ichibangai\images  にする
    3. ファイル名を  event-hirunomi  にする
    4. 保存


■ 画像がまだ無くてもアプリは動きます

  画像が見つからないときは、壊れたアイコンではなく
  🎪 の色付きブロックが表示されるようにしてあります。
  画像を置いた瞬間に、チラシが表示されるようになります。


■ ファイルの種類が JPG ではない場合

  PNG など別の形式で保存した場合は、
  data\events.js の中の

      image: 'images/event-hirunomi.jpg',

  という行の「.jpg」を「.png」に書き換えてください。
  （1文字直すだけです）


■ 月イチ番街のポスター画像（11枚）

  月ごとのポスターを、下の名前で保存してください。
  月の数字は必ず2桁（01, 02, …, 12）にしてください。

    tsukiichi-01.jpg  … 1月「新春福めぐり」
    tsukiichi-02.jpg  … 2月「お気に入り探し」
    tsukiichi-03.jpg  … 3月「ありがとう＆新発見」
    tsukiichi-04.jpg  … 4月「一番街新発見」
    tsukiichi-05.jpg  … 5月「食べ歩きフェス」
    tsukiichi-06.jpg  … 6月「アートストリート」
    tsukiichi-07.jpg  … 7月「夏の縁日」
    tsukiichi-09.jpg  … 9月「街歩きスタンプラリー」
    tsukiichi-10.jpg  … 10月「ハンドメイドマーケット」
    tsukiichi-11.jpg  … 11月「お店体験」
    tsukiichi-12.jpg  … 12月「クリスマス」

  ※ 8月は event-hirunomi.jpg（昼飲み＆限定ランチフェア）が
     その月の回にあたるので、tsukiichi-08.jpg は不要です。

  ※ 年を入れていないので、毎年おなじ画像を使い回せます。

  画像がまだ無いあいだは、「9月」のように月の数字を大きく出した
  カードが代わりに表示されます。壊れて見えることはありません。
  画像を置けば、その瞬間から画像に切り替わります。
  （データもコードも書き換える必要はありません）


■ 別のイベントに画像を付けたいとき

  1. 画像をこのフォルダに入れる
  2. data\events.js のそのイベントに
       image: 'images/ファイル名.jpg',
     の1行を足す

  image を書かなければ、画像は表示されません（エラーにはなりません）。


■ 注意

  ・ファイル名は半角の小文字だけにしてください。
    日本語・空白・大文字が入ると、ネット公開したときに
    表示されないことがあります。
  ・写真が大きすぎると表示が遅くなります。
    横幅 1000ピクセルくらいまでで十分です。
